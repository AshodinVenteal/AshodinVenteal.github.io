Mina ModAPI Enemy Spawn Example

A tiny code-mod example showing the shortest useful path from MinaMod_Init to spawning an entity through Mina's public ModAPI.

The Important Line

Mina->SpawnEntity(ENTITYTYPE_TEST_TRAINING_DUMMY);

The generated mod installs a FixedUpdate hook and calls this when N is pressed in-game.

Files

  • Mod manifest
  • Build script
  • README

Build

python create_modapi_enemy_spawn_example.py
cd EnemySpawnExample
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

Install

%APPDATA%\Yacht Club Games\Mina the Hollower\mods\EnemySpawnExample

Copy mod.yc and the built mod.dll there, then launch Mina with -mod -mod-allow-code.
